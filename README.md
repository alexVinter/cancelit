# 💥 УЩЕМИСЬ

> **«Загрузите свою рекламу и узнайте, кто из-за нее ущемится».**  
> Сатирическая нейросеть гипер-обиженного пользователя, которая находит 100% поводов для бойкота в любой рекламе, выставляет индекс токсичности и генерирует вирусную карточку «ТОТАЛЬНАЯ ОТМЕНА» для публикации в соцсетях.

---

## ⚡ Особенности

- 📸 **Мультимодальный анализ**: распознает изображения, позы людей, текст на плакатах, композицию и скрытые подтексты.
- 🎯 **Убер-обидчивый системный промпт**: гиперболизация микроагрессий, эйджизма, лукизма, классового угнетения и задетых чувств всех категорий граждан.
- 📋 **Вставка из буфера (Ctrl + V)**: сделайте скриншот (Win+Shift+S) и сразу нажмите `Ctrl + V` на странице для мгновенного анализа!
- 🎴 **Вирусная карточка Отмены (Shareable Card)**:
  - Штамп «ТОТАЛЬНАЯ ОТМЕНА» / «УГОЛОВКА ЗА КРИНЖ».
  - Шкала задетых чувств (0–100%).
  - Список ущемленных групп с эмодзи.
  - Анатомия микроагрессий (по пунктам).
  - Сгенерированный тред в Твиттере/X с тысячами ретвитов.
  - Сатирический совет маркетологу.
  - **Кнопка скачивания в PNG (2x разрешение)** для Telegram, Stories и X.
- 🚀 **5 готовых мировых скандалов**:
  1. *Apple («Раздави человеческое творчество» — реклама iPad Pro Crush)*
  2. *Bud Light («Самый дорогой бойкот в истории рекламы» — коллаборация с Дилан Малвейни)*
  3. *Balenciaga («Грязные кеды за $1850» — Paris Sneakers)*
  4. *Gillette («Лучший мужчина, который может быть»)*
  5. *Pepsi («Кендалл Дженнер и протесты»)*
  *Работают мгновенно без ввода API-ключа!*

## 🚀 Быстрый запуск

1. Перейдите в папку проекта:
   ```bash
   cd offended-ai
   ```

2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере: [http://localhost:5173](http://localhost:5173)

---

## 🔑 Подключение API-ключа для своих картинок

- Для анализа собственных картинок используется **Google Gemini 2.0 / 1.5 Flash**.
- Ключ можно бесплатно получить за 1 минуту в [Google AI Studio](https://aistudio.google.com/app/apikey) (без привязки банковских карт).
- Ключ вводится в шапке сайта по кнопке **«API Ключ»** (сохраняется в вашем браузере), либо в файле `.env`:
  ```env
  VITE_GEMINI_API_KEY=ваш_ключ_здесь
  ```

## 🛠 Технологии

- **Frontend:** React 19 + TypeScript + Vite
- **Стилизация:** Tailwind CSS v4 + Unbounded / Inter fonts (по гайдам `ui-ux-pro-max`)
- **Шеринг:** `html-to-image` (экспорт PNG в высоком качестве) + `canvas-confetti`
- **Иконки:** `lucide-react`
- **AI Core:** Gemini 2.0 Flash Multimodal Vision
